# Controle de Hábitos

Projeto web desenvolvido para ajudar no acompanhamento de hábitos diários, permitindo organizar atividades e visualizar o progresso ao longo do tempo.

## 🚀 Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades
- Acompanhamento de hábitos diários.
- Interface visual para organização dos hábitos.
- Estilização com CSS.
- Interatividade utilizando JavaScript.

## 💻 Como executar o projeto
1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html no navegador.

## 📂 Estrutura do projeto
- index.html — estrutura da página.
- index.css — estilos e identidade visual.
- index.js — lógica e interatividade.
- README.md — documentação do projeto.
