# Controle de Hábitos

Projeto web desenvolvido para praticar JavaScript e ajudar na organização de hábitos diários. Permite cadastrar, editar e excluir hábitos, mantendo os dados salvos no navegador mesmo após recarregar a página.

## 🚀 Tecnologias utilizadas
- HTML5 — estrutura da página.
- CSS3 — estilização e organização visual.
- JavaScript — lógica da aplicação, eventos e manipulação do DOM.
- localStorage — armazenamento dos hábitos no navegador.
- JSON — conversão dos dados para salvar e recuperar a coleção de hábitos.

## ✨ Funcionalidades
- Cadastro de hábitos com nome, categoria e meta diária.
- Edição dos hábitos cadastrados.
- Exclusão de hábitos.
- Validação para impedir o cadastro de hábitos sem nome.
- Criação dinâmica dos cartões de hábitos.
- Persistência dos dados com localStorage.
- Recuperação dos hábitos salvos ao recarregar a página.
- Identificação única dos hábitos com crypto.randomUUID().
- Edição e exclusão corretas de hábitos que possuem o mesmo título.
- Geração de identificadores para hábitos antigos que ainda não possuem um id.

## 🧠 Conceitos praticados
- Manipulação do DOM e criação dinâmica de elementos.
- Eventos e funções JavaScript.
- Arrays de objetos.
- Métodos de array: forEach(), find(), findIndex() e splice().
- Identificação de objetos por meio de IDs únicos.
- Conversão de dados com JSON.stringify() e JSON.parse().
- Persistência e recuperação de dados com localStorage.
- Controle de versão com Git e publicação do projeto no GitHub.

## 💻 Como executar o projeto
1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html no navegador.
